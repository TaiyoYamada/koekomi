# 設計判断の記録（ADR）

大きな設計判断を、**なぜそう決めたか**とセットで残す場所です。

コードのコメントは「この行が何をしているか」を説明できますが、
「なぜ別の道を選ばなかったか」は書きにくい。半年後の自分や、
引き継ぐ人がいちばん知りたいのはそこなので、ここに置きます。

| #                                                | 決めたこと                              | 状態 |
| ------------------------------------------------ | --------------------------------------- | ---- |
| [0001](0001-three-servers-are-for-redundancy.md) | 3台は冗長化であって負荷分散ではない     | 採用 |
| [0002](0002-one-line-is-the-unit-of-work.md)     | 作業単位を1行にする（強制中断をやめる） | 採用 |
| [0003](0003-client-owns-the-artifacts.md)        | 作品の音声はクライアントが所有する      | 採用 |
| [0004](0004-timeline-is-the-single-source.md)    | 再生規則はタイムライン1つに集約する     | 採用 |
| [0005](0005-round-robin-scheduling.md)           | 生成はラウンドロビンで配る              | 採用 |

## 書き方

1ファイル1決定。テンプレートは既存のものを真似てください。

```
# NNNN. 決めたこと（一言で）

## 状況
何が問題だったか。数字があれば数字で。

## 決定
どうすると決めたか。

## 理由
なぜ。捨てた選択肢と、捨てた理由も。

## 結果
良くなったこと。代わりに引き受けた不都合。
```
