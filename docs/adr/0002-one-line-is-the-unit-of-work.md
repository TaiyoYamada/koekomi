# 0002. 作業単位を1行にする（強制中断をやめる）

## 状況

以前は「16行まとめて1リクエスト」で、詰まったときに
`asyncio.wait_for` でタイムアウトさせていた。

```python
async with generation_lock:
    files = await asyncio.wait_for(synthesize_lines(...), timeout=180)
```

しかし重い処理は `asyncio.to_thread` の別スレッドで動いており、
**Python のスレッドは外から止められない**。結果:

1. タイムアウトでコルーチンは抜け、`async with` がロックを解放する
2. **GPU上ではスレッドが走り続けている**
3. 次のリクエストがロックを取り、同じGPUで2件目が始まる
4. さらに遅くなる → またタイムアウト → 悪化し続ける

**混雑時にタイムアウトが発火するほど状況が悪くなる**構造だった。

## 決定

作業単位を **1行（数秒）** にする。ワーカーは1行ずつ取り出して処理し、
キャンセルは「次の行を取り出さない」だけにする。

## 理由

キャンセルできないなら、**キャンセルしたくならない粒度にすればよい**。
強制中断が要らなくなり、最大待ちは1行ぶんになる。

実装の工夫でバグを避けるのではなく、モデルの選択でバグの発生余地を無くす。

## 結果

副次的に、次が全部ついてきた:

- **部分成功** — 16行目で失敗しても15行は使える（以前は全部ゼロ）
- **進捗** — 1行できるごとに結果が返る（1コマ目を再生しながら4コマ目を待てる）
- **待ち順位** — 出せるようになった
- 210秒の同期POSTが消え、iOS Safari が fetch を切る問題も消えた

引き換えに、ジョブの状態管理（`application/jobs.py`）が必要になった。
